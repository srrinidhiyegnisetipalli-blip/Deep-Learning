# Lending Club Loan Default Prediction Using Deep Learning

## Overview

This project focuses on predicting loan default risk using historical Lending Club loan data. Financial institutions rely on accurate risk assessment models to identify borrowers who are more likely to default on their loans.
The objective of this project is to develop a deep learning model capable of classifying loans based on repayment behavior and borrower characteristics.

## Methodology

The project follows a structured machine learning workflow:

* Data Cleaning and Preprocessing
* Exploratory Data Analysis (EDA)
* Categorical Feature Transformation
* Feature Engineering
* Correlation Analysis and Feature Selection
* Deep Learning Model Development using TensorFlow/Keras
* Model Evaluation and Performance Analysis

## Technologies Used

* Python
* Pandas
* NumPy
* TensorFlow
* Keras
* Scikit-learn
* Matplotlib
* Seaborn

## Results
A Deep Learning classification model was developed to predict the likelihood of loan default using borrower and loan-related attributes. The model demonstrates the application of neural networks in financial risk assessment and binary classification problems.

## Key Skills Demonstrated
* Data Preprocessing
* Exploratory Data Analysis
* Feature Engineering
* Deep Learning
* Classification Modeling
* Financial Risk Analytics
* Model Evaluation

## Conclusion
This project demonstrates how deep learning techniques can be applied to financial datasets to predict loan repayment behavior and support data-driven lending decisions. The approach can be extended further through model optimization, hyperparameter tuning, and deployment for real-world risk assessment applications.
