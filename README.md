# Lending Club Loan Default Prediction

This project focuses on predicting loan defaults using historical Lending Club loan data and Deep Learning techniques.

The notebook includes:
- data preprocessing
- feature transformation
- exploratory data analysis (EDA)
- feature engineering
- correlation analysis
- deep learning model development
- model evaluation

Concepts covered:
- Deep Learning
- Binary Classification
- Feature Engineering
- Data Visualization
- Artificial Neural Networks (ANN)
- Financial Risk Prediction

Libraries used:
- Python
- Pandas
- NumPy
- TensorFlow / Keras
- Scikit-learn
- Matplotlib
- Seaborn
